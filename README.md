# Facial Expression Recognition

Machine Learning project for detecting facial expressions using Python and OpenCV.

## 📌 Project Overview
This project classifies facial expressions using Machine Learning techniques and image processing.

## 🚀 Technologies Used
- Python
- OpenCV
- NumPy
- Scikit-learn
- Jupyter Notebook

## 📊 Features
- Facial expression detection
- Emotion classification
- Accuracy comparison charts
- Confusion matrix visualization
- Heatmap analysis
